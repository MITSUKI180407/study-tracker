# Study Tracker

Pythonで作成した、勉強時間を記録・管理するシンプルなアプリです。

CLI版に加えて、Tkinterを使用したGUI版も作成しました。

## 作成目的

Pythonの学習を進める中で、学んだ内容を実際のプログラムで活用するために作成しました。

勉強時間を記録し、過去の記録や科目ごとの合計時間を確認できるようにしています。

## 機能

- 科目と勉強時間の記録
- CSVファイルへのデータ保存
- 過去の勉強記録の表示
- 科目ごとの合計勉強時間の集計
- 入力値のチェック
- Tkinterを使用したGUI操作

## 使用技術

- Python
- Tkinter
- CSV

## ファイル構成

- `main.py`：CLI版
- `gui.py`：GUI版
- `records.csv`：勉強記録を保存するファイル

## 実行方法

### GUI版

`gui.py`を実行します。

科目と勉強時間を入力して「記録する」ボタンを押すと、記録がCSVファイルに保存されます。

画面上で過去の勉強記録と、科目ごとの合計勉強時間を確認できます。

### CLI版

`main.py`を実行するとメニューが表示されます。

1. 勉強を記録する
2. 過去の記録を見る
3. 科目別の合計時間を見る
4. 終了

## 工夫した点

最初にCLI版を作成し、その後、より操作しやすくするためにTkinterを使用してGUI版へ発展させました。

また、CSVファイルを利用することで、アプリを終了した後も勉強記録が残るようにしました。
