# Study Tracker

Pythonで作成した、学習内容と勉強時間を記録・管理するシンプルなデスクトップアプリです。

大学の勉強、資格勉強、読書、プログラミングなど、分野を問わず自主学習の記録に使用できます。

CLI版を作成した後、より使いやすくするためにTkinterを使用したGUI版へ発展させました。

## 作成目的

Pythonを学習する中で、文法を覚えるだけではなく、実際にプログラムを作りながら理解を深めたいと考え、Study Trackerを作成しました。

自分自身も大学の勉強や資格勉強、プログラミングなど複数の学習をしているため、「何を・どのくらい勉強したか」を簡単に記録できるアプリを目指しました。

## 対象ユーザー

大学の講義、資格勉強、読書、プログラミングなど、分野を問わず自主的に学習している人を対象としています。

## 主な機能

- 学習内容と勉強時間の記録
- 過去の学習記録の表示
- 学習内容ごとの合計時間の集計
- 記録の編集
- 記録の削除
- 入力内容のチェック
- 大文字・小文字の違いをまとめた集計

詳しい動作については [SPECIFICATION.md](SPECIFICATION.md) にまとめています。

## 実行方法

### GUI版

`gui.py` を実行します。

学習内容と勉強時間を入力して「記録する」を押すと、学習記録を保存できます。

### CLI版

`main.py` を実行すると、ターミナル上にメニューが表示されます。

## 工夫した点

最初からGUIを作るのではなく、まずCLI版を作成して基本的な処理を確認し、その後Tkinterを使ったGUI版へ発展させました。

また、実際に使用することを考えて、0分や文字列などの不正な勉強時間を保存できないようにしました。

記録を間違えた場合に修正できるよう、編集・削除機能も追加しています。
