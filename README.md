# Study Tracker

Pythonで作成した、勉強時間を記録・管理するシンプルなアプリです。

## 作成目的

Pythonの学習を進める中で、学んだ内容を実際のプログラムで活用するために作成しました。
勉強時間を記録し、過去の記録や科目ごとの合計時間を確認できるようにしています。

## 機能

- 科目と勉強時間の記録
- CSVファイルへのデータ保存
- 過去の勉強記録の表示
- 科目ごとの合計勉強時間の集計
- 入力値の簡単なチェック

## 使用技術

- Python
- CSV

## 実行方法

main.pyを実行するとメニューが表示されます。

1. 勉強を記録する
2. 過去の記録を見る
3. 科目別の合計時間を見る
4. 終了
